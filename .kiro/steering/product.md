# Product Overview

Controller Test App is a modern web application for testing game controllers with real-time visual feedback and diagnostics. The app helps gamers and developers test and diagnose issues with their game controllers, including stick drift detection, button problems, and general controller functionality.

## Key Features

- **Controller Detection**: Automatically detects connected controllers via the Gamepad API
- **Multi-Controller Support**: Works with Xbox, PlayStation, and generic controllers  
- **Visual Feedback**: Real-time visual representation of button presses and stick movements
- **Stick Drift Detection**: Identifies and visualizes analog stick drift issues
- **Diagnostics Dashboard**: Detailed view of all controller inputs and their values
- **Responsive Design**: Works on desktop and mobile browsers that support the Gamepad API

## Target Users

- Gamers experiencing controller issues
- Developers testing controller integration
- Hardware enthusiasts diagnosing controller problems

## Browser Compatibility

The application works best in modern browsers that support the Gamepad API:
- Chrome (full support)
- Edge (full support) 
- Firefox (full support)
- Safari (limited support)
