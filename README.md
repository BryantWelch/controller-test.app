# Controller Test App

![Controller Test App](https://img.shields.io/badge/Controller%20Test-App-7dfcbd)
![License](https://img.shields.io/badge/license-MIT-blue)

A modern web application for testing game controllers with real-time visual feedback and diagnostics.

## 🎮 Overview

Controller Test App is a free, open-source web application designed to help gamers and developers test and diagnose issues with their game controllers. Whether you're experiencing stick drift, button problems, or just want to make sure your controller is working properly, this tool provides a simple and intuitive way to visualize controller inputs in real-time.

## ✨ Features

- **Controller Detection**: Automatically detects connected controllers via the Gamepad API
- **Multi-Controller Support**: Works with Xbox, PlayStation, and generic controllers
- **Visual Feedback**: Real-time visual representation of button presses and stick movements
- **Stick Drift Detection**: Identifies and visualizes analog stick drift issues
- **Diagnostics Dashboard**: Detailed view of all controller inputs and their values
- **Responsive Design**: Works on desktop and mobile browsers that support the Gamepad API

## 🚀 Getting Started

### Live Demo

Visit [https://controller-test.app](https://controller-test.app) to use the application online.

### Development

To run the project locally:

1. Clone the repository:
   ```
   git clone https://github.com/BryantWelch/controller-test.app.git
   cd controller-test.app
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
